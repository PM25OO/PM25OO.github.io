了解 Android 系统与应用

Android 系统架构

  • Linux 内核层

为 Android 设备的各种硬件提供了底层的驱动（显示，音频，摄像，蓝牙，WIFI，电源…）

  • 系统运行库层

一些C/C++库（SQLite，OpenGL，Webkit），一些 Android 运行时库，其中包含 Dalvik（-> ART） 虚拟机，它使得每一个Android应用都能运行在独立的进程中，并且拥有一个自己的虚拟机实例。相较于Java虚拟机，Dalvik 和 ART 针对手机内存、CPU 性能有限等情况做了优化处理。

  • 应用框架层

提供各种 API 以供开发者构建自己的应用程序

  • 应用层

所有安装在手机上的应用程序

Android 应用开发特色

  • 四大组件

    • Activity（应用程序的门面，用户看到的一切）
    • Service（后台服务相关）
    • BroadcastReceiver（接受电话，短信等广播消息，发送广播消息）
    • ContentProvider（使应用程序之间共享数据的手段）

  • 各种系统控件

提供了丰富的系统自带的控件效果（例如 Material Design 等等）

  • SQLite数据库

自带了这种轻量级、运算速度极快的嵌入式关系型数据库，还可以通过 Android 封装好的 API 进行操作，方便了数据的存取

  • Log.i(...) info 级别
  • Log.w(...) warn 级别
  • Log.e(...) error 级别

Kotlin 之于 Java

Kotlin的语法更加简洁，对于同样的功能，使用 Kotlin 开发的代码量可能会比使用 Java 开发的减少 50% 甚至更多。另外，Kotlin 的语法更加高级，相比于 Java 比较老旧的语法，Kotlin 增加了很多现代高级语言的语法特性，使得开发效率大大提升。还有，Kotlin 在语言安全性方面下了很多工夫，几乎杜绝了空指针这个全球崩溃率最高的异常

val value，用来声明一个不可变的变量（不可重新赋值），对应 Java 的 final

  • 项目复杂时，可变变量会导致出现一些很难排查的问题，Kotlin 通过设计这两个关键字，使开发者主动思考设计变量的可变性。一个好的习惯是，永远优先使用 val，仅当无法满足需求时再使用 var
